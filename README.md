Tanzania Premier League Match Predictor – Gambling Assistant(eSportApp):

 A mobile application that predicts Tanzania Premier League match outcomes using a machine learning model, designed as a gambling decision‑support tool.  
 **Final year project** – Bachelor of Science in Information Technology and Systems, Mzumbe University 2022-2025.

## Overview

This project predicts the outcome (home win, draw, away win) of Tanzania Premier League matches based on historical team performance, recent form, head‑to‑head records, and other football statistics. The prediction is delivered through a **eSport mobile app**, and the core prediction engine is a **machine learning model** built with Python (scikit‑learn / TensorFlow).
 
 Features
- Match outcome prediction (Win/Draw/Loss) for upcoming Tanzania Premier League games  
- Confidence score displayed with each prediction  
- Clean Flutter UI – easy for end‑users to select teams and view predictions  
  -Machine learning backend – trained on real league data (if dataset is available, or using simulated/demo data)  
  Fast offline model– model runs locally on device after initial load
